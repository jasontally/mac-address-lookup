# auth.md

This site and its MCP endpoint require no authentication and no registration.
Agents access the service anonymously.

- Audience: any agent or client
- Registration: none required (anonymous access)
- Registration method: none (no provisioning endpoint)
- Credential use: none (no credentials issued)
- register_uri: none
- agent_auth: anonymous (no identity assertion, no dynamic client registration)
- MCP endpoint: https://mac.jasontally.com/mcp
- Documentation: https://mac.jasontally.com/help#mcp
