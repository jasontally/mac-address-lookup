    What this tool tells you

    Every network interface has a MAC address, and its first three bytes — the OUI — are registered with the IEEE Registration Authority. This lookup resolves that prefix against the complete IEEE registries (MA-L, MA-M, MA-S, IAB, and CID) using longest-prefix matching, so small blocks resolve to the correct organization.

    • Vendor and registered organization, with block type and address range
    • Randomization detection — modern phones randomize Wi-Fi addresses, which have no vendor
    • Virtual-machine prefixes for VMware, VirtualBox, Hyper-V, Parallels, Xen, QEMU/KVM, and Docker
    • Prefix lineage — acquisitions and renames, with the dates each change was first observed
    • Format conversions: colon, hyphen, Cisco dot, plain hex, EUI-64, and IPv6 link-local

    Frequently asked questions

    Why does my MAC address show no vendor?

    Phones, tablets, and laptops often randomize their Wi-Fi MAC address per network. Randomized addresses set the locally administered bit and deliberately contain no manufacturer information, so no vendor can be resolved. Look up the hardware address from the device settings instead.

    Is this lookup private?

    Yes. The IEEE dataset is downloaded once and every lookup is computed in your browser. The address you type is never sent to a server.

    Does the vendor tell me the exact device?

    No. The prefix identifies the organization that registered the block, not the device model. A vendor match can also be inherited from an acquisition, which is what prefix lineage shows.
